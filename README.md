# Teiul Verde

Демо электронного меню для ресторана: гость сканирует QR-код на столе и открывает меню на телефоне. Есть три языка (румынский, русский, английский), вкладки по разделам, вес, цены и пометки «вегетарианское» и «острое». Ресторан выдуманный, страница сделана как пример работы.

Живая версия: https://dancchik.github.io/menu-demo/

Карточка с QR-кодом для стола (формат A6, печатается из браузера): https://dancchik.github.io/menu-demo/qr.html. Сам код лежит в `qr.svg`, для нового клиента его можно сделать заново, например так: `python -c "import segno; segno.make('URL', error='m').save('qr.svg', scale=10, border=2)"`.

Обычный HTML, CSS и JS, без сборки и библиотек. Блюда и цены берутся из Google Таблицы (одна строка на блюдо), владелец меняет их сам с телефона: https://docs.google.com/spreadsheets/d/1SbscpXH3KgjiXTJIJJr2XBP2vMrRKTc2VpLsijYk3-E

Название, контакты и запасной вариант меню на случай, если таблица не загрузилась, лежат в `menu.js`. Под новое заведение: копия таблицы с доступом «все, у кого есть ссылка, читатель», её id в `menu.js` и свои цвета в `style.css`.

Локально: `python -m http.server` в этой папке и открыть http://localhost:8000. Язык можно задать ссылкой, например `?lang=ru`.

Рядом лежат два примера прайса для салонов на том же движке: маникюр https://dancchik.github.io/menu-demo/salon/ и барбершоп https://dancchik.github.io/menu-demo/barber/. Общий код в `prices/`, у каждой страницы свой `data.js`. Кнопка записи ведёт в Telegram, звонок на телефон.
